# Проект: Анализ различий выручки пользователей с подпиской и без

**Инструменты:** Python, pandas, scipy.stats, matplotlib  

## О проекте
В этом проекте я проверил гипотезу о различии выручки у двух групп пользователей. Задача типична для продуктовой аналитики: понять, приносит ли подписка значимый эффект, и не списать ли разницу на случайность.

> 💡 Аналогия из мотокросса: это как проверить, даёт ли новая настройка вилки реальный прирост времени круга или ты просто «попал в ритм» на одной тренировке. Чтобы понять точно, нужно несколько заездов и статистика, а не ощущения.

## Что сделано
- Загрузил и проверил данные (CSV), убедился в отсутствии пропусков и выбросов.
- Разделил пользователей на две группы: с подпиской и без.
- Посчитал выборочные средние, стандартные отклонения и дисперсии.
- Провёл двухвыборочный t‑тест (Welch’s t‑test) для сравнения средних.
- Применил поправку Бонферрони для контроля доли ложных отклонений при множественных тестах.
- Визуализировал распределения выручки и средние значения по группам.

## Результаты
- Средняя выручка пользователей с подпиской: **X руб.**
- Средняя выручка пользователей без подписки: **Y руб.**
- t‑статистика: **Z**
- p‑value: **P**
- Вывод: нулевая гипотеза **отвергается / не отвергается** при уровне значимости α = 0.05 (с учётом поправки Бонферрони).
